# Prefab Deploy 0.1.1 交付记录

Minecraft 1.21.1，Java 21，NeoForge 21.1.248 编译，运行最低版本 `[21.1.248,)`。本次未发布。

## 已实现的修改

- 独立“预制建筑”创造标签页，部署工具图标，包含工具和位置信标，保留原工具标签页入口。
- 淡灰半透明圆角面板、白色阴影文字、橙色强调与悬停/选中状态；列表、独立 3D 预览、费用条件和操作按钮随 GUI 尺寸安排。保留搜索、滚动、拖动与缩放，世界背景可见；HUD 长文字按宽度换行。
- Mod 界面、HUD、工具提示、自动费用/条件摘要和原生玩家错误支持中英文翻译；作者名称、分类、条件说明和脚本普通文字保持原样。规则失败语义与文字分开。
- R 顺时针旋转 90°，四方向循环。主手工具或信标的 Shift+右键优先取消活动定位，对方块和空气均有效；施工开始后仅提示无法取消。Esc 保持 Minecraft 默认行为。
- 信标对方块普通放置，对空气直接浮空放置，Shift+滚轮调距离；普通放置失败不会转为浮空放置。
- 服务器创造模式报价免除材料、XP、ViScriptShop 和自定义费用，不调用费用提供者回调；费用豁免及实际信标消耗数量持久化，成功只返还消耗的信标。切换模式和重启不重算固定报价，旧日志使用原凭据及兼容默认字段。

## 编译与交付范围

初次执行 `Build.ps1 -Task @('jar', 'sourcesJar')` 和 `tools/package_release.py --build-only` 时仅编译打包，未运行测试。随后用户明确要求运行测试，已完成 10 项 JUnit、无联动/全联动各 31 个 GameTest 入口、三个阶段独立 JVM 冷启动恢复、真实客户端及 1 万/5 万/10 万位置性能验证。详细范围、首轮测试夹具问题和最终证据见 [TESTING-0.1.1.md](TESTING-0.1.1.md)。没有测试 21.1.252，也未发布。

本次编译日志为 `test-results/build-0.1.1.log`，机器可读状态为 `test-results/acceptance.json`。当前运行日志和截图位于 `test-results/release-0.1.1/`；`acceptance-0.1.0.json` 及其运行记录保留为历史证据。原先仅编译的 0.1.1 摘要另存 `acceptance-0.1.1-build-only.json`。

交付文件：`dist/prefabdeploy-0.1.1.jar`、`prefabdeploy-0.1.1-sources.jar`、`prefabdeploy-0.1.1-source.zip`、示例建筑 ZIP、性能样例 ZIP，以及 `SHA256SUMS.txt`。安装时客户端和服务器同时替换旧版，同一实例仅保留一个版本。

## 剩余逐项手工验收清单

自动验证已覆盖大部分核心行为，GUI 640×400/427×267 截图已检查。以下每项包含更广的交互组合，未全部逐项手工操作，因此保留未勾选状态；不要将它们解释为自动套件未通过。

- [ ] 中英文创造物品栏显示专用标签页、正确图标和两个物品；原工具标签页仍有入口。
- [ ] 320×240 及较大 GUI 尺寸、不同 GUI 缩放下，列表、预览、费用和按钮无重叠，世界背景可见，文字可读；长费用和错误悬停能看全文。
- [ ] 搜索、列表滚动、选中/悬停、3D 拖动和缩放正常；切换语言后 Mod 文字改变，作者与脚本文字保持原文。
- [ ] 准星定位按 R 依次 0°/90°/180°/270°/0°；按修饰键不会触发逆向旋转。
- [ ] 跟随预览、A/B/C 各阶段、固定预览、验证中分别持工具或信标，Shift+右键方块和空气都先取消；不触发容器交互、固定、部署或新信标放置。
- [ ] 施工开始后 Shift+右键只提示无法取消，任务与 HUD 保持施工状态；Esc 关闭界面或打开原版菜单，不取消定位。
- [ ] 普通信标对方块按正常位置放置；对空气按浮空距离放置；Shift+滚轮调距离，权限/高度/边界检查不被绕过；普通放置失败不产生额外浮空信标。
- [ ] 生存三点消耗三枚并成功返还三枚；创造三点返还零枚；混合模式只返还生存实际消耗数，满背包返还可领取，重复结算不重复给付。
- [ ] 创造模式 GUI 显示免费；材料、XP、ViScriptShop 余额不减少，自定义成本提供者没有收费回调；未解锁、无领地权限和无效位置仍拒绝。
- [ ] 生存模式正常收取原材料/XP/货币/自定义费用，资金不足不改世界；已固定报价后切换模式不重算。
- [ ] 旧日志继续按原费用恢复；新创造豁免及信标数量在重启后保持；失败恢复不额外退款或返还信标。
