# Prefab Deploy 0.1.1 运行验证

2026-10-03，Minecraft 1.21.1、NeoForge **21.1.248**、Java 21.0.11，Windows Server 2025。本次没有测试 21.1.252。报告位于 `test-results/release-0.1.1/`，测试世界均位于本地缓存的独立目录，未使用玩家世界。

## 自动验证范围

- 10 项 JUnit：坐标旋转、边界、压缩状态索引及原子日志完整性。
- 无联动 GameTest：31 个入口，实际执行 27 项核心场景，4 个联动专用入口跳过。
- 全联动 GameTest：31 项全部执行并通过，包含 KubeJS、FTB Teams/Quests/Chunks、ViScriptShop，版本与 API 文档版本表一致；结果见 `gametest-compat.log` 和当前验收 JSON。
- 新增 7 项 0.1.1 回归：创造费用及全部提供者回调豁免、保存后切换模式、旧报价收费与幂等退款、文字与规则失败语义分离、真实普通/浮空信标消耗、验证中取消和施工后拒绝取消、创造模式安全检查、新日志恢复与信标数量。
- BLOCKS、TICKS、COMMIT 三阶段独立 JVM 强制退出和冷启动恢复；验证世界、库存、生成实体和重复结算/退款。
- 真实 OpenGL 客户端：中文界面文字、拖动与缩放、GUI 缩放 2/3、R 顺时针四方向循环、Shift+右键跟随/验证取消、真实浮空 A/B/C、三枚信标消费与返还、创造首次部署免费和生存随后部署收取一枚绿宝石。

客户端运行元数据和断言标记保存在 `client-benchmark.json`，原始运行记录为 `client-smoke.log`，实际运行截图位于 `screenshots/`。

## 性能

AMD EPYC 7F52，128 GiB 内存，NVIDIA RTX 5060 Ti。1280×800，渲染距离 8，模拟距离 5，关闭 VSync，最高 200 FPS。GUI 验证包括实际逻辑尺寸 640×400 和 427×267，截图经过检查；每组热预览包含至少 400 帧。全服调度默认 2 ms 软预算、512 次操作。

部署额外主线程 p95 ≤5 ms、热预览 CPU/GPU p95 ≤3 ms 的目标达到。100,000 位置的完整服务器 Tick p95 为 4.394 ms，所有样例最终更新排空。调度单次最大值为 22.324 ms，2 ms 是软预算。预览计时覆盖预览渲染代码，不能当作整个游戏帧时间；堆占用包括客户端和集成服务器，不能全部归因给 Mod。其他机器、模组和蓝图仍需独立测量。

## 首轮问题及处理

`attempts/` 保留失败尝试日志。没有修改发布逻辑来绕过断言。

- 验证取消：任务在后续调度移出队列，原测试在同一调用栈中过早检查 `busy`；调整为等待队列排空。
- COMMIT 冷启动：实体已保存在独立实体区块文件，恢复完成后区块票据释放，FakePlayer 不提供普通玩家加载票据；测试保持实体区块可观察后验证唯一实体。磁盘记录和任务 UUID 已核对。
- 客户端报告路径：手工运行命令误传 PowerShell provider 路径，修正为普通文件系统路径。
- 客户端 Shift 模拟：LocalPlayer 从 `Input.shiftKeyDown` 读取状态，改为设置真实输入字段并触发 NeoForge 输入事件。
- C 信标测试视线被 A 阻挡：改为从东侧对空气瞄准，仍保留正常方块命中拒绝浮空的行为。后台步骤异常现在传播到客户端并终止测试；每轮使用独立客户端世界。

以上是测试夹具和运行脚本修正，安装 JAR 的业务逻辑保持本次测试前的实现。
